# Art Vandeley — Changelog

What came off the dock, newest first. Served at https://vandeley.art/changelog.md and read by `/art-vandeley:news`. One `## <version> — <date>` heading per release.

Update: `/plugin marketplace update vandeley` then `/plugin update art-vandeley@vandeley`, then restart Claude Code.

## 0.11.0 — 2026-09-26

- **New skill `/news`** — the harbor bulletin. Tells you what shipped since the crate you have installed, and how to update.
- **New skill `/radar`** — the lookout. A dated brief of agentic news (deploythebox, Hacker News, Anthropic, the Claude Code changelog), searched live in your session. Nothing is stored or proxied.

## 0.10.1 — 2026-09-26

- **Fix `/iterate`** — reads the marketplace name from `claude plugin list` before refreshing, instead of assuming `vandeley`.

## 0.10.0 — 2026-09-26

- **New skill `/handoff`** — the change of watch. Lands the in-flight action, writes a self-contained watch log, and launches a background relief whose sole task is to keep building.

## 0.9.0 — 2026-09-26

- **New skill `/lets-get-cracking`** — the cast-off. Breaks a planning loop: names the stall, drops plan mode and planning rituals, builds the smallest working slice with at most one question.

## 0.8.0 — 2026-09-22

- **New skill `/drama`** — the gangway. Stages a page's call to action: each button fades in place into the one field it needs; a finished action offers the next with the data already given.

## 0.7.0 — 2026-09-09

- **New skill `/unslopify`** — the fitting-out berth. Sourced design-practice audit (Primer, Tailwind, Refactoring UI) and a refit in your own tokens.

## 0.6.0 — 2026-07-18

- **New skills `/iterate` and `/opinions`** — the dry dock (refits the plugin itself) and the pilots' council (expert perspectives, devil's advocate seated, 2–4 options).

## 0.4.0 — 2026-07-17

- **New skill `/next-steps`** — the dispatch desk. Reads git history, the roadmap, and the working tree, then calls the next moves in order.
